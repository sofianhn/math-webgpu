Knobs below change how fast / how stably it fits the training distribution — not the domain itself. Domain = integers 0–99. Values ≥ 100 (three digits) are out of distribution.

What data is it training on?

Each example is a random expression with operands in 0–99 and op in {+, −, ×, ÷}. Features are place-value one-hots (tens digit + ones digit for each operand), not a single flat ID per number. Answers are classification classes 0–999 (huge products are resampled so they fit).
